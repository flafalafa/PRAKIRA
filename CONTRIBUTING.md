# Contributing to PRAKIRA

First off, thank you for considering contributing to PRAKIRA! It's people like you that will help give families enough time to protect their homes from flooding.

## Branching Strategy

We follow a feature-branch workflow:
- `main` is the production-ready branch.
- `develop` is the active development branch.
- Create feature branches from `develop`: `feature/your-feature-name`
- Create bugfix branches from `develop`: `bugfix/issue-description`

## Pull Requests

1. Fork the repository and create your branch from `develop`.
2. Ensure your code follows the principles in `AGENTS.md`.
3. Add or update tests as appropriate.
4. Update documentation if you are changing functionality.
5. Ensure the test suite passes locally.
6. Open a Pull Request targeting the `develop` branch.

## Commit Messages

- Use conventional commits (e.g., `feat: add rain radar integration`, `fix: correct layout on mobile dashboard`).
- Keep the subject line concise.
- Provide a detailed body explaining *why* the change was made if it's complex.
