# T-502: Mesin Analisis Cuaca (Weather Analysis Engine)

## Ringkasan
Berhasil mengimplementasikan **Weather Analysis Engine** sebagai subsistem pertama dari *Flood Decision Engine*. Modul ini berspesialisasi sebagai "Ahli Meteorologi Digital". Tugasnya adalah meneliti tumpukan data cuaca dan curah hujan murni (*Canonical Data*), lalu merangkumnya menjadi indikator badai, tingkat keparahan (*Severity*), dan tren curah hujan. Sesuai desain, mesin ini **tidak** memprediksi banjir, melainkan murni mengekstrak wawasan cuaca.

## Keputusan Arsitektur
1. **Pemisahan Konteks Cuaca (`WeatherContext`)**: Ketimbang memasukkan seluruh data dunia ke mesin ini, ia hanya menerima apa yang ia butuhkan: `weather_observations` dan `rainfall_observations`. Ini menjaga fokus mesin.
2. **Kalkulator Metrik Terpusat (`WeatherMetrics`)**: Berbagai rumus statistik cuaca (rata-rata curah hujan, akumulasi total, persentase kelengkapan data) dipusatkan di sini. Aturan-aturan (*Rules*) tidak perlu menghitung dari nol, mereka cukup memanggil metrik yang sudah ada.
3. **Aturan Cuaca Modular (`HeavyRainRule`, dll)**: Saya menciptakan struktur kelas dasar `BaseWeatherRule`. Saat ini sudah tertanam aturan pendeteksi *Heavy Rain* (Hujan Lebat). Karena sistem ini menggunakan pola Registry, puluhan aturan lain terkait badai atau tekanan udara dapat ditambahkan kelak sebagai *plugin*.
4. **Kebijakan Degradasi Kepercayaan (`WeatherPolicyEngine`)**: Arsitektur ini tidak naif. Jika persentase kelengkapan data di bawah 50% (karena sensor mati atau jaringan putus), *Policy Engine* akan bertindak agresif memangkas tingkat *Confidence* ke angka 0.4 dan mencatat alasan *"Missing observations detected"* secara paksa.

## Batasan yang Diketahui
- `WeatherMetrics` saat ini mendeteksi tipe data hanya dengan mengecek apakah `parameter` bernama "rainfall", "precipitation", atau "rain". Sebaiknya ke depan dibuatkan enumerasi standar (Enum) untuk tipe parameter.
- Mesin Analisis Cuaca ini belum menyentuh metrik spesifik radar (*Radar Metrics*), karena hal tersebut mungkin akan membutuhkan *plugin* tersendiri di masa depan.

## Peningkatan Kedepan
- **Integrasi Radar Geospasial**: Jika kolektor RainViewer (T-404) telah aktif sepenuhnya mengumpulkan pergerakan awan dalam format titik kordinat, `WeatherAnalysisEngine` dapat diekspansi untuk melacak *Trajectory* pergerakan awan secara temporal.
- **Kecerdasan Buatan (AI Forecast Fusion)**: Modul ini dirancang agar kompatibel jika dihubungkan dengan model Prediksi Cuaca Berbasis AI (Misalnya NeuralGCM atau model lokal) untuk membandingkan data aktual vs tebakan AI.
