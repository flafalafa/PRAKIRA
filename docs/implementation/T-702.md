# T-702: Batasan Keamanan dan Autentikasi API Enterprise (Enterprise API Authentication & Security Boundary)

## Ringkasan
Berhasil mengimplementasikan **Enterprise API Authentication & Security Boundary**. Modul ini adalah "Tembok Pertahanan" (*Firewall*) logika yang melindungi seluruh rute API publik kita dari akses tak berizin. Sesuai dengan spesifikasi, modul ini mendirikan arsitektur keamanannya saja, bukan mengimplementasikan sistem manajemen pengguna (*User Management System*) secara penuh.

## Keputusan Arsitektur
1. **Polimorfisme Autentikasi (*Authentication Abstraction*)**: Kita tidak mengikat mati sistem ke satu jenis login. Saya membuat `BaseAuthenticationProvider` dan `AuthenticationRegistry`. Saat ini sudah tersedia penyedia untuk **JWT** (untuk aplikasi warga) dan **API Key** (untuk integrasi server pemerintah/layanan pihak ketiga).
2. **Konteks Keamanan Terpusat (*Security Context*)**: Alih-alih melempar data *user* mentah ke *router*, *provider* akan menghasilkan objek `SecurityContext`. Objek ini dibawa ke sepanjang sisa siklus *request*. Ini memisahkan secara total antara "bagaimana user login" dengan "siapa user ini".
3. **Kebijakan RBAC & PBAC**: Autorisasi dibangun ganda. Menggunakan *Role-Based Access Control* (contoh: `Role.ADMIN`) dan *Permission-Based Access Control* (contoh: `Permission.NOTIFICATION_MANAGE`). Kebijakan `Least Privilege` diterapkan dengan ketat.
4. **FastAPI Dependency Injection**: Perlindungan *endpoint* dilakukan dengan cara yang sangat elegan dan deklaratif. Cukup tambahkan `Depends(require_role(Role.ADMIN))` di definisi fungsi *route*, dan FastAPI akan otomatis menolak akses jika syarat tidak terpenuhi.

## Batasan yang Diketahui
- `JWTAuthenticationProvider` saat ini masih menggunakan logika *mock* string statis (karena dependensi pustaka kriptografi JWT yang sebenarnya belum ditambahkan). Arsitektur sudah siap untuk disuntik implementasi `PyJWT` atau `python-jose` sungguhan di masa depan.
- Tidak ada fitur registrasi, lupa *password*, atau penyimpanan kredensial ke database. Ini adalah tugas modul Manajemen Pengguna terpisah.
