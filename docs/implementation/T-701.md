# T-701: Fondasi API Publik Enterprise (Enterprise Public API Foundation)

## Ringkasan
Berhasil mengimplementasikan **Enterprise Public API Foundation**. Ini adalah gerbang utama yang menghubungkan seluruh kecerdasan *backend* Flood Guardian (yang dibangun di Sprint 1-6) dengan dunia luar (misalnya Aplikasi Mobile Flutter, Dashboard BPBD, dll). 

## Keputusan Arsitektur
1. **Pemisahan Keras (Strict Separation)**: API Layer ini berfungsi murni sebagai **Adaptor**. Ia diharamkan untuk menghitung skor risiko, membuat keputusan peringatan, atau mengeksekusi logika bisnis apa pun. Tugas utamanya hanyalah memvalidasi HTTP Request, memanggil *Application Services*, dan membungkus hasilnya ke dalam format respons yang standar.
2. **Kontrak Respons Standar (*Response Contract*)**: Semua respons API (baik Sukses maupun Gagal) memiliki struktur yang seragam. Setiap respons dibekali blok `meta` yang berisi `request_id` dan `timestamp`. Hal ini krusial untuk melacak (tracing) perjalanan sebuah HTTP Request dari Frontend hingga ke dalam Decision Engine.
3. **Penyembunyian DTO (*Data Transfer Object*)**: Entitas Domain dan Model Database (SQLAlchemy) tidak pernah diekspos langsung ke publik. API layer memiliki *Schemas* (Pydantic) mandiri. Hal ini mencegah kebocoran struktur database internal ke pihak luar.
4. **Versioning Maju (*Forward-compatible Versioning*)**: Router dibangun di bawah prefix `/api/v1/`. Jika kelak di tahun 2028 ada perombakan besar-besaran pada struktur JSON, kita cukup membuat `/api/v2/` tanpa merusak kompatibilitas aplikasi lama yang masih dipakai warga di desa.
