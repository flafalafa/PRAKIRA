# T-807 Enterprise Alert & Notification Mobile Integration

## Overview
This document outlines the implementation details for T-807, which integrates the existing Flood Guardian backend alert and notification architecture into the Flutter mobile application.

## Key Constraints Respected
1. **No Backend Modification**: All endpoints hit existing backend routes as defined in Sprint 7.
2. **No Business Logic on Mobile**: The mobile app does not calculate risk, implement deduplication, quiet hours, or notification routing. It simply consumes the API.
3. **FCM Abstraction**: A `PushNotificationService` interface was introduced, with a `LocalPushNotificationService` stub. Firebase and FCM dependencies were strictly avoided as the backend FCM integration is not yet complete.
4. **API Endpoints Respected**:
   - `GET /{area_id}/notifications` for history
   - `GET /notifications/{notification_id}` for detail
   (No mark-as-read, preference toggles, etc. were created)

## Architecture
1. **Domain Layer**:
   - `PushNotificationService`: Abstract interface defining core push capabilities (`initialize`, `requestPermission`, `subscribeToTopic`, `unsubscribeFromTopic`).
2. **Data Layer**:
   - `NotificationRemoteDataSource`: Calls the actual backend API to retrieve paginated notifications and individual details.
   - `NotificationRepository`: Coordinates the data fetching and converts exceptions to standard AppFailures.
   - `LocalPushNotificationService`: Stub implementation simulating subscription to area topics without requiring FCM.
   - `NotificationModel`: Strict parsing from the Sprint 7 Pydantic schemas.
3. **Presentation Layer**:
   - `AlertDetailScreen`: Displays the detailed `AlertModel` using a structured format.
   - `NotificationHistoryScreen`: Retrieves and lists historical notifications by `areaId`.
   - `NotificationRouter`: Handles deep-link payload routing to the relevant UI screens based on area ID validation.
   - `DashboardScreen`: Updated to include a notification bell icon and tappable `AppAlertBanner`.
